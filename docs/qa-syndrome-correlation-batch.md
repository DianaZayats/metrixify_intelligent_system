# Пакет повідомлень для кореляцій (дні 26–55)

Див. [syndrome-track-qa.md](./syndrome-track-qa.md). Кожен день містить сон, стрес, енергію, каву, симптоми.

Копіюйте блоки в Telegram **по одному на день** або:

```bash
npm run qa:seed-syndrome-batch -- <ваш_telegramUserId>
```

Після відправки: `npm run qa:backfill-entry-dates`, потім **Analyze** на головній.
